# ReadMe
## 1  写在前面
本仓库主要装载本人在ZJU学习《数字逻辑设计》课程时的实验工程。

使用的IDE是Vivado，编写Verilog语言。

上传该仓库是因为自己学习该课程时在实验部分真的是吃了很多的亏，很多困难依靠Github上面前辈们的经验、作品得到了解决，因此也想尽自己的绵薄之力来帮助大家解决学习过程中遇到的困难。

受本人代码能力、风格因素限制，工程代码可能有很多写的繁杂混乱的地方且个人风格比较明显，大家可以根据自己的情况选择性参考~

最后也想说下，本人感觉实验部分确实多经过自己的摸爬滚打才能领悟到更深层次的东西。实验不能脱离理论，因此也希望大家在狠抓实验的时候不要忽略了理论知识的学习。实验过程中会遇到很多困难，变量大小写的错误、数据位宽的错误、分号的漏打、数组向量维度的错误等等等等，但请始终保持细心、理智，有逻辑、目的的去设计电路、解决bug，最后的结果一定不会辜负付出！
